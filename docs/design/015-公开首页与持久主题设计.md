# 015 公开首页与持久主题设计

- 状态：Accepted
- 日期：2026-08-31
- 对齐基线：`video-server` 公开项目首页与一键主题切换

## 目标

未登录用户先看到可理解项目用途的原生公开首页，而不是被认证门禁直接送入登录表单。登录仍是任务、文件、账户与管理数据的强制边界。公开页、认证页和登录后页面共用一个浅色/深色一键切换入口，并保存非敏感主题偏好。

## 路由与认证边界

- App 启动时仍先恢复 Keychain/Keystore 中的 Refresh Credential，恢复期间不泄露业务内容。
- 恢复后未登录落到 `/` 的公开首页；登录或注册是用户主动进入的独立路由。
- `/downloads/*` 与 `/admin/*` 等资源路由继续要求原生 Bearer 会话，匿名深链接统一进入登录。
- 登录或注册成功后，`/` 展示真实下载工作区；退出后同一路由收敛为公开首页。
- 公开首页只包含静态项目介绍，不调用需要 Access Token 的历史、Provider、文档或媒体接口。

## 公开首页

- 顶部保留“帧取”品牌、主题按钮和登录入口。
- 首屏说明开源、自托管、公开视频、剧本文档和服务端 AI 分析边界，并提供创建账户操作。
- 能力与信任信息使用原生排版、Lucide 图标、语义标题和无边框分隔，不复制 Web DOM 或引入 WebView。
- 中文、英文、390×844、大字体、屏幕阅读器与深浅主题均保持可读。

## 主题

- 只提供浅色与深色两个状态；按钮一次点击直接切换，不显示菜单或“跟随系统”。
- 首次安装使用浅色主题，之后通过 `shared_preferences` 的异步 API 保存非敏感偏好。
- Refresh Credential 仍只进入安全存储；主题偏好不得与认证凭据共用存储或生命周期。
- 主题按钮出现在公开首页、登录注册页和所有登录后顶部导航，图标与 tooltip 表达点击后的目标主题。

## 替代关系

本设计替代 007 中“未登录只能看到登录/注册、退出回登录”的路由规则，以及 002 中“主题只影响当前进程”和 009 中“主题入口仅登录后可见”的范围；其他认证安全、主导航和数据授权规则保持不变。
