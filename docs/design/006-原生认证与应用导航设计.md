# 006 原生认证与应用导航设计

- 状态：Accepted
- 日期：2026-08-30

## 1. 目标

补齐 Flutter App 的注册、登录、会话恢复、账户状态与退出体验，并把顶部品牌栏和底部一级导航整理为可扩展的原生应用壳层。

## 2. 导航层级

- 顶部栏负责应用身份与当前会话快捷入口：左侧保留“帧取 / Framegrab”文字，右侧显示“登录”或当前用户名入口；不重复图形 Logo。
- 底部 Tab Bar 负责首页、下载记录、剧本文档、平台状态、我的五个一级目的地。选中项显示图标和标签，未选中项以图标保持稳定触控宽度，减少中英文和大字体拥挤。
- 登录与注册是独立全屏路由，提供明确返回和相互切换，不在底部 Tab 内嵌表单。
- “我的”在未登录时提供登录/注册入口；登录后展示用户身份、外观设置与退出。

## 3. 认证状态

状态机为：`restoring → signedOut → submitting → signedIn`，任一远程失败回到可重试状态并显示服务端可读错误。

- Access Token 仅存在于内存。
- Refresh Credential 仅进入 `flutter_secure_storage`，启动时用它恢复会话。
- refresh 单飞；失败清除本地会话并回到 signedOut。
- logout 先请求撤销，再无条件清除本地 Credential。
- 不解析 JWT、不使用浏览器 Cookie、不使用 WebView 或 localStorage。

## 4. 表单与反馈

- 登录：邮箱、密码、显示/隐藏密码、提交、注册交叉入口。
- 注册：用户名、邮箱、密码、确认密码、显示/隐藏密码、提交、登录交叉入口。
- 用户名 2–32 个字符；密码 8–128 个字符；邮箱使用标准格式校验；确认密码必须一致。
- 覆盖初始、校验失败、提交中、服务端失败、成功、会话恢复失败和退出中状态。
- 错误使用文本与语义播报，不只依赖颜色；键盘 Next/Done 顺序和焦点清晰。

## 5. 契约

唯一远程事实为 `video-server` 026 的 `/api/app/v1/auth/*` Bearer 契约及冻结 App OpenAPI 快照。客户端通过生成包访问 API，不手写平行 DTO。

## 6. 可访问性

- 390×844、中文/英文、深浅主题与辅助功能大字体均不得溢出。
- 所有表单字段有可读 label、错误、键盘类型与密码切换名称。
- 顶部会话入口和五个 Tab 保留按钮/Tab 角色、完整名称与选中状态。
- reduced motion 下不依赖位移动画理解状态。
