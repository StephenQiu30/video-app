# 003 方案一视觉深化与 Web 普通用户功能对齐设计

- 状态：Accepted
- 日期：2026-08-13
- 用户决策：使用 Product Design 方案一；风格与 Web 保持一致；App 使用 Flutter 原生组件；覆盖 Web 普通用户功能

## 1. 设计方向

方案一采用编辑式单任务首屏：80px 左对齐品牌栏、直接的大标题、克制说明、单链接输入、黑色主操作、事实型使用提示和固定四项底部导航。视觉 token 继续来自 Web：`#FAFAFA / #0A0A0A / #F1F1F1`、6px 圆角、无渐变、无重阴影、以留白和细分隔线建立层级。页面不使用装饰性编号眉题，也不以无法验证的安全或隐私承诺制造信任感。

App 不复制 Web 的 Header、Sheet 或 DOM 控件。iOS/Android 使用安全区、系统键盘、系统返回、底部导航、动态文字和屏幕阅读器语义；品牌、文案层级、图标家族和状态语义与 Web 同源。Web 使用自托管 Geist；App 使用平台系统字体并通过统一 `TextTheme` 对齐字号、字重、字距与行高，这是为了动态字体和原生可读性的有意差异。

## 2. Flutter UI 组件

当前运行时组件为 Flutter Material 3：

- 应用壳：`MaterialApp.router`、`Scaffold`、`AppBar`、`SafeArea`、`IndexedStack`。
- 页面与滚动：`CustomScrollView`、`SliverPadding`、`ListView`、`ConstrainedBox`。
- 输入与操作：`TextField`、`InputDecoration`、`FilledButton`、`IconButton`、`SwitchListTile`。
- 导航与反馈：`NavigationBar`、`NavigationDestination`、`CircularProgressIndicator`、`Divider`、`Semantics`。
- 品牌与图标：`flutter_svg` 渲染同源 Logo；Material Symbols 提供原生、可访问的系统图标。
- 状态与导航基础设施：Riverpod、go_router；二者不属于视觉组件。

shadcn/ui 与 Radix UI 继续只服务 Web。Flutter 不引入 React/DOM 运行时，也不做逐组件映射。

## 3. 普通用户功能信息架构

| App 入口 | 覆盖的 Web 能力 | 原生呈现 |
| --- | --- | --- |
| 视频解析 | URL 校验、媒体解析、格式选择、创建下载 | 首页内逐步展开；格式使用原生单选列表 |
| 下载记录 | 搜索、状态筛选、分页、恢复详情、重试、获取文件 | 底部页签 + 原生列表；详情使用全屏路由 |
| 下载详情 | 进度、实时状态、取消、重试、授权文件下载 | 线性进度、确认对话框、系统文件保存/分享 |
| AI 分析 | Skill 配置、创建、进度、取消、重试、删除、结果、报告导出 | 下载详情中的分区与原生 Tab；报告交给系统文件能力 |
| 平台状态 | 能力、访问模式、验证状态、刷新 | 只读列表与语义状态标签 |
| 我的 | 登录、注册、资料更新、退出、主题 | 受保护路由、原生表单、安全存储与设置 |

Web 管理员的下载分析、平台目录和用户管理不属于“普通 Web 功能”，继续保留在 Web 管理端。

## 4. 差异与边界

- 合理差异：底部导航替代 Web 移动 Sheet；Material Symbols 替代 Web 的 Phosphor React；平台系统字体替代 Web 自托管 Geist；详情使用系统返回；文件使用系统保存/分享；触控目标、键盘、焦点和动态文字遵循平台规范。
- 不合理差异：不同色板、不同圆角、卡片堆叠、重阴影、伪造格式/进度/平台状态、把 Web Cookie 当作原生会话。上述做法禁止进入实现。
- 当前阻塞：服务端只有浏览器 HttpOnly Cookie 会话，尚未冻结原生 Access/Refresh、Bearer、WebSocket 和 App OpenAPI 契约。阻塞解除前只允许真实的本地输入与表现层，不得宣称业务 E2E 完成。

## 5. Design Acceptance Criteria

- DAC-003-01：方案一首屏在 390×844 基线保留品牌、编辑式层级、主任务和四项底部导航。
- DAC-003-02：页面使用 Flutter 原生组件与 Material Symbols，无 WebView、shadcn 或 Radix 运行时。
- DAC-003-03：普通用户能力信息架构覆盖 Web 的解析、下载、历史、AI、平台、认证和账户；管理端明确排除。
- DAC-003-04：任何远程数据只来自冻结并生成的 App OpenAPI，不使用 Cookie 绕过或模拟数据。
