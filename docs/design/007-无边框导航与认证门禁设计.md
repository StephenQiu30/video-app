# 007 无边框导航与认证门禁设计

- 状态：Accepted
- 日期：2026-08-30
- 视觉基准：[`references/007-borderless-navigation-selected.png`](references/007-borderless-navigation-selected.png)

## 目标

将 Flutter 主框架收敛为与 Web shadcn/ui、Radix UI 同源的中性组件语言，并把认证从可选入口升级为应用级门禁。用户启动 App 后先恢复安全会话；未登录时只能访问登录和注册，登录成功后才能进入主导航。

## 视觉系统

- 顶部 Navbar 仅保留“帧取”文字品牌，不重复“首页”、登录或账户入口。
- 首页内容 Tabs 使用无容器、无描边的三等分触发器；选中态以黑色图标、较高字重和短下划线表达。
- 底部 TabBar 无外框、无顶部分隔线、无选中短横线、无药丸背景；五个目的地始终显示图标和短标签。
- 底部选中态只使用黑色 Lucide 图标、黑色文字与较高字重，未选中项使用中性灰图标与常规字重。
- 输入区域以轻中性色填充而非描边分组；主要动作保持黑底白字、6px 圆角。
- 页面标题、汇总、列表、详情元数据与分析结果依靠留白和排版建立层级，不使用装饰性分隔线、卡片外框或描边按钮；次要动作使用实心中性色或文字按钮。
- 深浅主题、动态字体、触控目标、焦点、Semantics tab 角色和 selected 状态继续由 Flutter 原生能力承担。

## 组件边界

- 不引入整套平行 Flutter UI 框架；保留 Material 3 的路由、表单、焦点、语义和平台行为。
- 使用 shadcn/ui 默认的 Lucide 图标语言；`lucide_icons_flutter 3.1.17` 是本机 Flutter 3.44 可解析的最新兼容版本。
- `AppTheme` 是颜色、字体、圆角与状态 token 唯一来源；业务页面不复制 shadcn Web 组件代码。
- `AppBottomNavigation`、`ContentIntakeSelector` 和 `DownloadAppBar` 是本轮可复用原生组件。

## 认证门禁

- 启动期进入只读的品牌恢复页，不短暂展示主内容或登录表单。
- Refresh Credential 恢复成功后进入 `/`；缺失、失效或不可用时进入 `/auth/login`。
- 未登录访问任意主页面统一重定向登录；登录和注册互相可达。
- 已登录访问认证页面统一重定向 `/`；退出完成后立即回到登录页。
- Access Token 继续仅留内存，Refresh Credential 继续仅进入 Keychain/Keystore。

## 非目标

- 不改变五个一级目的地和首页三种素材入口的业务含义。
- 不引入 WebView、浏览器 Cookie、第二套路由器或第二套状态管理。
- 不在本轮接入仍未冻结的下载、文档和平台状态业务接口。
