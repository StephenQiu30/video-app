# 011 账户退出布局与应用图标复核设计

- 状态：Accepted
- 日期：2026-08-30

## 1. 目标

调整“我的”页面的退出登录层级，并复核 iOS、Android 原生应用图标与模拟器实际安装结果，避免把其他 Bundle 的默认图标误认为“帧取”。

## 2. 退出登录布局

- 账户区只展示当前用户身份，不再把退出动作夹在账户信息与管理中心之间。
- 管理员先看到“管理中心”，退出登录始终作为页面最后一个操作出现。
- 退出操作使用全宽、左对齐、无边框的危险色文字按钮；通过留白与前述内容分组，不增加卡片或分割线。
- 保留既有退出逻辑、忙碌禁用状态、可访问性语义与自动回到登录页的行为。

## 3. 应用图标事实来源

- 品牌源仍为 `assets/brand/logo.svg` 与 `assets/brand/logo.png`。
- 原生不透明图标源仍为 `assets/brand/app_icon.png`，iOS AppIcon 与 Android launcher 资源由该品牌构图派生。
- iOS 使用 `com.stephenqiu.framegrab` 和显示名“帧取”；模拟器中 `com.stephenqiu.then` / “于是”是独立应用，不属于本项目，也不在本次范围内删除或修改。
- 验收同时检查源文件、编译后的 AppIcon 和“帧取”桌面入口，不能只凭另一应用的桌面截图下结论。

## 4. 边界

本修订不改变账户契约、管理员权限、底部导航、Logo 图形构图或其他已安装应用。
