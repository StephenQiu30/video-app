# 002 Web 对齐的 App 首页表现层设计

- 状态：Accepted
- 日期：2026-08-13
- 用户确认：App 页面效果继续与 Web 服务实现保持一致

## 1. 目标与边界

本阶段把 `video-server` 当前首页的品牌 Header、编辑式标题、链接输入、主操作、状态提示、页脚信任信息和深浅主题转换为 Flutter 原生表现层。全局导航按用户反馈使用固定底部菜单栏，视觉事实仍来自 Web 的 `globals.css` 与首页组件，App 不建立平行色板或营销文案。

本阶段只实现可运行、可测试的 UI 和本地 URL 归一化。真实解析、登录、刷新、下载、历史和 WebSocket 仍等待原生会话与 App OpenAPI 契约，不复用 Cookie，不渲染伪造媒体结果。

## 2. 视觉映射

- Header 使用 80px 内容高度、32px 同源品牌 SVG、17px 品牌文字和至少 44px 的菜单触控目标。
- 首页使用 16px 手机 gutter、40px Hero 顶部留白、直接的两行编辑式标题、15px 描述、64px 输入与主操作；不使用装饰性编号眉题。
- 浅色继续使用 `#FAFAFA / #0A0A0A / #F1F1F1 / #111111`；深色使用 `#0A0A0A / #F5F5F5 / #1C1C1C / #F5F5F5`。
- 圆角固定 6px，不增加卡片外壳、阴影、渐变或装饰动效；分组仅用留白和必要分隔线。
- 600px 以下输入与主操作纵向满宽，较宽设备可恢复 Web 的输入加 148px 操作列。

## 3. 原生适配

- Web 的移动 Sheet 转换为更符合原生心智的 Material 3 底部菜单栏，固定提供“视频解析、下载记录、平台状态、我的”四个目的地。
- 主题切换放在“我的”页签且只影响当前进程；持久化必须由后续非敏感设置设计拉动。
- 尚未开放的历史与平台状态进入后显示准确空态并解释契约边界，不伪造数据。
- 有效 URL 在生产依赖缺失时显示明确的“契约尚未冻结”状态，不发送网络请求。

## 4. Design Acceptance Criteria

- DAC-002-01：首页信息层级、品牌资产、语义 token 与 Web 当前实现同源。
- DAC-002-02：390px 宽下无横向溢出，输入、主操作和状态纵向可达。
- DAC-002-03：底部菜单、浅色、深色、动态文字、屏幕阅读器与系统返回具备原生行为。
- DAC-002-04：URL 校验与 Web 规则一致，拒绝多 URL、凭据 URL 和非 HTTP(S) 输入。
- DAC-002-05：未接入 Cookie、WebView、真实业务 API 或伪造解析数据。
