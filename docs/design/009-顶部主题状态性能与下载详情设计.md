# 009 顶部主题、状态性能与下载详情设计

- 状态：Accepted
- 日期：2026-08-30
- 对齐基线：`video-server` Web 下载记录与下载详情

## 目标

将全局主题切换放入登录后始终可见的顶部导航；消除平台状态页每次进入都等待实时请求的体验；允许用户从下载历史进入真实任务详情，并与 Web 端使用同一服务端资源和核心信息层级。

## 导航与主题

- 顶部导航继续显示“帧取”品牌文字，右侧提供 44×44 最小触控目标的明暗主题按钮。
- 按钮图标与可访问名称表达点击后的目标主题，不增加边框、短横线、胶囊或阴影。
- “我的”页面只保留账户身份与退出登录，不再重复提供主题开关。
- 下载详情沿用同一顶部品牌和主题入口，左侧使用原生返回按钮，并支持 iOS 返回手势。

## 平台状态性能

- `GET /api/providers` 当前运行证据约为 2 秒；延迟来自服务端合并 Runner 上下文和多类验证证据，不使用本地静态平台列表替代。
- 平台状态数据改为登录会话级缓存，在主应用壳建立后立即预取；用户首次打开状态 Tab 时优先消费已完成或进行中的同一请求。
- 切换 Tab 不销毁成功数据。用户下拉刷新时保留现有内容，后台获取新快照，避免重新显示整页阻塞加载。
- 冷启动请求尚未完成时使用与最终列表结构接近的骨架占位和明确加载语义；错误仍提供重试。

## 下载详情

- App 专用 OpenAPI 契约新增 `GET /api/downloads/{job_id}`，继续使用 `NativeBearerAuth`、统一刷新和生成客户端，不手写 DTO。
- 历史行整体成为可访问的导航目标，并显示向右提示；点击进入 `/downloads/:jobId`。
- 详情展示标题、来源、格式、任务状态、阶段、进度、执行次数、文件可用性、创建/更新/完成时间和安全归类后的失败原因。
- 活跃任务在详情页可手动下拉刷新；本轮不接入尚未冻结的 App WebSocket、文件授权、视频预览或 AI 分析操作。
- 详情接口失败时展示可重试错误；访问不属于当前账户或不存在的任务时不回退历史列表数据伪造详情。

## 非目标

- 不修改 `video-server` Provider 证据计算与安全边界。
- 不引入第二套主题状态、第二个 HTTP 客户端或平行数据模型。
- 不实现下载文件、取消、重试、缩略图、视频播放或 AI 分析操作。
