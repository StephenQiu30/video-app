- 输出：下载工作台的输入、解析、视频信息和清晰度选择交互。

## 1. 页面职责

`/download` 只负责输入一个视频链接、展示解析结果、选择一个清晰度并创建下载任务。不显示任务历史、字幕、播放列表、音频下载或底层 yt-dlp 参数。

## 2. 页面结构

页面由三个纵向 ProCard 组成：

1. 输入区：`ProForm` + `ProFormText`，标签“视频链接”，主按钮“解析视频”。
2. 视频区：缩略图、标题、平台和时长，使用 `ProDescriptions`，不显示原始 URL。
3. 格式区：单选清晰度列表和“开始下载”按钮。

首屏同时展示能力边界和合法使用提示，但不能用大段说明阻塞主操作。

## 3. 用户流程

1. 用户输入 HTTP/HTTPS 链接并提交。
2. 表单进入 inspecting，禁用重复提交。
3. 解析成功后展示视频与格式，默认选中服务端返回的第一个格式。
4. 用户确认清晰度并创建下载任务。
5. 创建成功后立即跳转 `/download/jobs/:jobId`。

解析结果显示明确过期时间和“15 分钟内有效”。过期后禁用下载创建并要求重新解析。

## 4. 格式展示

每个选项显示：

- 清晰度 label、容器、FPS。
- 估算大小；null 显示“大小未知”，不能显示 0。
- `requires_merge=true` 时显示“音视频合并”辅助文本。

不展示 provider format ID、selector、仅视频格式或仅音频格式。解析新链接时必须清空旧格式、旧选择和旧错误。

## 5. 页面状态

`idle → inspecting → inspected | inspect_failed`

- idle：只有输入和说明。
- inspecting：按钮 loading，保留输入。
- inspected：显示视频和格式卡片。
- inspect_failed：保留输入，在当前 Card 显示可恢复错误。
- parsed result expired：显示 warning，禁用下载按钮。

## 6. 校验与错误

- 空值和非法协议由表单就地校验。
- 服务端 URL 禁止、不支持、DRM、超时或解析失败使用服务端 message。
- 系统错误由全局 Request Error 处理，页面提供“修改链接后重试”。
- 不把原始 URL 放入路由 query、日志、错误上报或页面标题。

## 7. 可访问性

- 输入和格式组有可见标签及错误关联。
- 单选项可键盘切换，主按钮有明确禁用原因。
- 缩略图 alt 使用安全标题；装饰图标对辅助技术隐藏。
- 加载状态不得只依赖旋转图标，必须显示“正在解析”。
