# App 与 Web 全业务一致性设计

状态：Accepted。范围依据用户确认覆盖全部业务页面。

真机连通验收使用与 App 相同的 Dio 配置和生成登录客户端，在目标手机上验证 HTTPS readiness 与空凭据的 422 校验响应；不登录、不创建账户、不清空 Keychain。诊断仅输出传输类型、底层异常类型及 OS/HTTP 状态码，不记录请求或响应内容。此检查不能替代真实账号登录与文件保存。

移动连接预算为 30 秒（原 5 秒在真机中继链路发生 connectionTimeout）；响应预算不变，不添加自动登录重试、证书例外、IP 回退或第二套网络客户端。延长连接预算仅提高短时链路波动容忍度，不承诺修复运营商、VPN、中继的丢包或长时间断连。

同一业务的操作、状态含义、校验边界和错误反馈以 Web 当前实现及服务端契约为基线；Web 不准确或过窄的文案同时修复。平台原生文件选择、安全存储、系统分享、导航布局和操作系统权限保留。

媒体展示遵循用户确认的“封面宽度统一，高度自适应”：同一布局统一宽度，图片解码后按原始比例完整铺满宽度，不固定高度、不拉伸、不裁切；内联视频按运行时真实显示宽高布局。竖图允许页面变长并滚动，不通过固定横框补边。尺寸未知或不可用时使用可读占位，不把占位高度强加给已加载媒体。

复用现有 Riverpod、Material 3、Dio、ARB 与 OpenAPI Generator。冻结客户端包含 48 个路径、56 个操作，恢复历史/管理筛选参数，加入用户资料、配置管理及 DOCX 导出；035 增量接入服务端只读运行诊断，不增加平行 DTO。

035 策略增量：选择器消费服务端允许策略、默认值与 hosts；改变策略清除旧解析并改变幂等指纹。未配置选项禁用，未准入访客不提供选项。共享 AppDropdownField 承载单项禁用；管理员诊断按需请求，明确配置/上下文不等于下载成功，保持原生认证边界。

列表状态按页面独立管理，搜索/筛选回第一页。资料保存经过 AuthenticatedRequest 的会话校验，返回结果额外校验用户 ID 和会话代次。配置编辑时禁止重复提交和中途关闭；密码及新凭据仅保留在表单内存。
