# App 与 Web 全业务一致性设计

状态：Accepted。范围依据用户确认覆盖全部业务页面。

同一业务的操作、状态含义、校验边界和错误反馈以 Web 当前实现及服务端契约为基线；Web 不准确或过窄的文案同时修复。平台原生文件选择、安全存储、系统分享、导航布局和操作系统权限保留。

复用现有 Riverpod、Material 3、Dio、ARB 与 OpenAPI Generator。冻结客户端包含 47 个路径、55 个操作，恢复历史/管理筛选参数，加入用户资料、配置管理及 DOCX 导出，不新增后端接口或平行 DTO。

列表状态按页面独立管理，搜索/筛选回第一页。资料保存经过 AuthenticatedRequest 的会话校验，返回结果额外校验用户 ID 和会话代次。配置编辑时禁止重复提交和中途关闭；密码及新凭据仅保留在表单内存。
