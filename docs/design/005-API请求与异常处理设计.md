## 1. 官方请求体系

前端完全使用 Ant Design Pro/Umi Max 官方体系：

- `@umijs/max` Request 是唯一 HTTP 客户端；不手写 Axios Instance。
- `src/app.tsx` 提供全局 RequestConfig。
- `src/requestErrorConfig.ts` 是 HTTP 与业务错误唯一入口。
- `@tanstack/react-query` 通过应用根部唯一 `QueryClientProvider` 管理查询、mutation、缓存和轮询。
- Umi Model 只保存客户端全局状态，不保存接口数据。

## 2. OpenAPI 生成

`@umijs/max-plugin-openapi` 读取服务端 `/openapi.json`，生成 TypeScript API 命名空间和 `src/services/` Service。生成目录只读，禁止手工维护第二份 DTO 或请求路径。

| 页面动作 | 服务端接口 |
| --- | --- |
| 解析视频 | `POST /api/v1/videos/inspect` |
| 创建/查询下载 | `POST /api/v1/download-jobs`、`GET /api/v1/download-jobs/{id}` |
| 获取文件 | `GET /api/v1/artifacts/{id}/download-url` |
| 创建/查询 AI | `POST /api/v1/download-jobs/{id}/ai-jobs`、`GET /api/v1/ai-jobs/{id}` |
| 展示 AI 结果 | `GET /api/v1/ai-results/{id}` |

OpenAPI 发生破坏性变化时生成步骤必须失败并要求先更新对应 Design，不通过 `any` 或兼容映射隐藏变化。

## 3. DTO、VO 与 Mapper

- 生成 DTO 与服务端 Request DTO、Response VO 一致。
- 页面不得使用数据库字段、Celery task ID 或 MinIO object key。
- 服务端 VO 已适合展示时直接使用，不机械创建前端 VO。
- 只有格式化时间/大小、组合字段或衍生 UI 状态时创建页面 VO 与 Mapper。
- 页面不传播无类型 `any` 或裸 JSON。

## 4. 统一响应

业务响应固定为：

```json
{"code":"SUCCESS","message":"success","data":{}}
```

`requestErrorConfig.errorThrower` 检查非 `SUCCESS` code 并抛出统一业务错误。HTTP 非 2xx、超时和断网由 Umi Request 处理；页面只处理能够提供当前上下文恢复动作的错误。

- DTO 字段错误：表单就地显示。
- 可恢复业务错误：当前 Card 内 `Alert` 或 `Result`。
- 未预期错误：全局 `notification.error`，不显示堆栈。
- 401/403 能力保留，但 MVP 不实现登录跳转。
- MinIO 文件不使用 JSON 包装；预签名 URL 接口仍使用统一响应。

## 5. React Query 规则

- Query Key 固定包含资源类型和 ID。
- 解析与任务创建使用 mutation；任务详情和结果使用 query。
- 只有幂等 GET 网络失败可自动重试。
- 创建任务 POST 不自动重放，避免重复任务。
- 查询取消使用 Umi Request/底层 Axios 提供的取消能力，不保留过期页面请求。

## 6. 安全与隐私

- 不在日志、错误上报或 URL query 中复制用户视频 URL。
- 不接受用户输入的 Header、Cookie、Endpoint、文件路径、Prompt 或模型密钥。
- 不使用 `dangerouslySetInnerHTML` 渲染标题、错误或 AI 内容。
- 生产 API Origin 固定配置，不提供任意服务端切换界面。
- 后端未就绪时显示服务不可用，不使用 Mock 数据伪装成功。

## 7. 执行验收标准

| 编号 | 必须证明 | 验证与证据 |
| --- | --- | --- |
| `W005-DAC-01` | Service 和 DTO/VO 全部由真实 Server `/openapi.json` 生成，重复生成零手工差异 | 官方生成命令、生成前后 diff 和 schema 来源记录 |
| `W005-DAC-02` | 业务页面只经生成 Service 和唯一 Umi Request 发请求，无手写 URL、Axios 实例、DTO 或 `any` | 依赖/源码/AST 扫描、TypeScript 和生产构建 |
| `W005-DAC-03` | `code/message/data` 解包与 422、业务错误、500、503、超时、断网行为完全一致且无 `request_id` | 请求/异常参数化测试和真实 Server 故障响应 |
| `W005-DAC-04` | GET 只在允许错误下有限重试，POST 不自动重放，卸载/切换时请求取消 | QueryClient 行为测试、请求计数和网络记录 |
| `W005-DAC-05` | Query Key、缓存失效、轮询和 mutation 边界稳定，不把服务端数据复制进 Umi Model | Hook 测试、缓存检查和源码扫描 |
| `W005-DAC-06` | URL、Secret、对象键和 AI 内容不进入路由 query、日志或错误上报，内容不通过 HTML 注入 | 敏感数据 canary、DOM/网络/日志和 XSS 测试 |
| `W005-DAC-07` | 完整 Server OpenAPI 重新生成后所有页面测试、类型检查和生产构建同时通过 | 跨仓 schema 记录、全量命令、退出码和构建产物检查 |
