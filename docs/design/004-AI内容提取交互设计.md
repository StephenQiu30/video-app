# 004 AI 内容提取交互设计

## 文档状态

- 状态：Accepted（2026-07-19；执行验收标准已按用户明确要求收紧）。
- 上游：[001 Web 总体架构](001-Web边界与总体架构设计.md)、[003 下载任务交互](003-下载任务与文件获取交互设计.md)。
- 输入：AI job ID、任务状态和结构化分析结果。
- 输出：AI 创建、进度、结果、失败和边界提示交互。
- 对应 PRD：[004 AI 内容提取交互需求](../prd/004-AI内容提取交互需求.md)。
- 服务端对应：[video-server 004](https://github.com/StephenQiu30/video-server/blob/main/docs/design/004-AI内容提取设计.md)。

## 1. 功能边界

AI 是下载成功后的可选操作，只提取视频语音中的摘要、核心要点和章节。

- 不展示或下载字幕文件。
- 不展示完整内部转写。
- 不承诺理解画面、图表、动作或人物。
- 不暴露 Whisper、Prompt、模型、Provider 或 API Key 配置。

## 2. 创建交互

用户从成功下载页点击“AI 内容提取”。Web 提交默认 `output_language=zh-CN`，成功后跳转 `/ai/jobs/:jobId`。

创建期间按钮 loading 且不可重复提交。下载任务失败、过期或文件缺失时不显示入口。

## 3. 任务状态

`loading → queued → running → succeeded | failed | expired`

- queued：显示“等待 AI 处理”。
- running：显示服务端 progress 和 transcribing/analyzing 阶段。
- succeeded：展示结构化结果。
- failed：展示安全错误和“返回视频下载”。
- expired：提示分析结果已过期，不伪造空结果。

轮询规则与下载任务一致：queued/running 每 2 秒刷新，终态停止。

## 4. 结果展示

使用三个 ProCard：

1. “视频摘要”：连续可读的 summary。
2. “核心要点”：语义列表形式的 key points。
3. “章节”：起止时间、标题和章节摘要。

页面顶部显示“结果仅基于视频语音，可能存在识别和总结误差”。不展示模型原始响应、Prompt、Token 或内部异常。

## 5. 失败处理

- `TRANSCRIPTION_FAILED`：提示语音无法识别或媒体处理失败。
- `AI_ANALYSIS_FAILED`：提示模型分析失败，可重新从下载成功页创建新任务。
- 查询临时失败保留上次数据并允许重试。
- 未知字段或结构化结果缺失视为错误，不能部分伪装成功。

## 6. 可访问性

- 章节使用语义列表而非仅视觉时间轴。
- 动态进度提供文字，不自动移动焦点。
- 长摘要可正常换行，手机端保持单列。
- AI 提示和错误使用可被辅助技术读取的 `Alert` 或 `Result`。

| 编号 | 必须证明 | 验证与证据 |
| --- | --- | --- |
| `W004-DAC-01` | 只从 succeeded 且未过期下载创建 AI 任务，默认 `zh-CN` 且重复点击不重复创建 | 状态/请求计数测试和真实 Server 创建记录 |
| `W004-DAC-02` | queued、transcribing、analyzing、succeeded、failed、expired 和未知状态均准确显示 | 状态/stage 矩阵与真实任务浏览器证据 |
| `W004-DAC-03` | 轮询只在进行态执行，隐藏、离线、卸载和终态停止且请求可取消 | Fake Timer、可见性、网络和取消测试 |
| `W004-DAC-04` | 真实结果完整映射 summary、key_points、chapters，章节时间合法；缺字段必须失败 | 真实 Provider 结果、schema/DOM 断言和页面截图 |
| `W004-DAC-05` | 页面不展示转写全文、Prompt、Token、原始响应、内部错误或画面推断 | DOM、网络、日志和源码扫描 |
| `W004-DAC-06` | 转写失败、模型失败、查询临时失败和过期提供准确且不误导的恢复动作 | 故障矩阵、重试行为和浏览器证据 |
| `W004-DAC-07` | 语音边界提示始终可见，章节语义、长文本、焦点和动态进度满足可访问性 | Testing Library、键盘和辅助技术检查 |
| `W004-DAC-08` | 从真实下载完成页创建 AI 到真实结果展示的端到端链路通过 | 真实 Server/Worker/Provider 浏览器录屏、网络记录和结果关联 |
