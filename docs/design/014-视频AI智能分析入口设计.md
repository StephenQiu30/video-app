# 014 视频 AI 智能分析入口设计

- 状态：Accepted
- 日期：2026-08-31
- 对齐基线：`video-server` Web 下载详情 `AnalysisPanel`

## 问题

服务端和 Web 已提供视频 AI 分析的 Skill 清单、创建、恢复、进度、取消、重试、删除与结构化结果，但 Flutter App 的专用 OpenAPI 白名单没有冻结任何普通用户 Analysis operation，下载详情因此完全缺少 AI 入口。

## 契约

App 新增并仅使用以下现有 `NativeBearerAuth` 契约：

- `GET /api/analysis-skills?input_kind=video`
- `POST /api/downloads/{download_id}/analyses`
- `GET /api/downloads/{download_id}/analysis`
- `GET /api/analyses/{analysis_id}`
- `POST /api/analyses/{analysis_id}/cancel`
- `POST /api/analyses/{analysis_id}/retry`
- `DELETE /api/analyses/{analysis_id}`

创建与重试分别使用稳定幂等键；401 继续走统一单飞刷新，资源归属由服务端校验。App 不读取 Web Cookie，不拼装平行 JSON DTO。

## 页面与状态

- 下载成功后，详情页展示“AI 智能分析”分区；下载未完成时不展示不可执行表单。
- 没有既有任务时读取视频 Skill，默认选中第一项，允许选择输出语言并编辑不超过 4,000 字的分析重点。
- 创建后独立展示分析状态、阶段、进度、执行代次和技术尝试；分析状态不得改写下载成功状态。
- 活跃分析每 2 秒通过 REST 收敛，直到成功、失败或取消；页面销毁后停止轮询。
- 活跃任务可取消，失败或取消任务可重试，删除需要二次确认。
- 成功结果按服务端判别联合类型渲染：视觉分析展示摘要、场景、分镜、高光和资产；视频文章展示导语、章节、要点、结语与局限。
- 错误只显示归类后的可行动信息，不展示 Provider 原始输出、Prompt 快照、Token 或私有地址。

## 移动体验

- AI 分区沿用当前无边框信息层级和动态字体，不复制 Web 桌面双栏。
- 配置表单为单列触控布局，主要操作最小高度 44；长结果一次只展示一个分类，避免横向溢出和同时构建全部分镜。
- 读取失败保留明确重试入口；操作失败保留现有任务和配置，不用假结果覆盖。

## 非目标

- 本轮不接入尚未冻结的 App WebSocket。
- 本轮不在设备运行模型、FFmpeg 或分析 Agent。
- Markdown/DOCX 报告的原生文件落盘与系统分享需要独立文件契约，本轮继续直接阅读结构化结果与服务端报告正文。
- 剧本文档分析入口另行接入，不把视频契约复用于文档。
