# 001 帧取移动 App 基础体验需求

- 状态：Accepted
- 日期：2026-08-12

## 1. 用户价值

用户可以在手机上粘贴有权处理的公开视频链接，查看服务端提供的真实格式，创建下载任务，跟踪进度，获取文件，并阅读 AI 视频分析结果，而无需打开浏览器 Web 平台。

## 2. 首期用户流程

1. 用户启动 App，完成注册/登录或恢复已有会话。
2. 在首页粘贴单个公开链接并提交解析。
3. 查看媒体摘要与服务端返回的真实格式，选择一个格式。
4. 创建下载任务并进入详情页。
5. 在前后台切换或网络恢复后继续查看准确进度。
6. 成功后将文件保存到系统位置或分享给其他 App。
7. 按服务端能力发起 AI 分析并阅读结构化结果。
8. 在历史页查找自己的任务，在账户页管理基本资料与退出登录。

## 3. 功能范围

- 邮箱注册、登录、会话恢复和退出。
- 单链接解析、媒体摘要和格式选择。
- 下载创建、进度、失败原因、取消、重试和文件获取。
- 下载历史搜索、筛选、分页和详情恢复。
- AI 分析创建、状态、失败恢复和结果阅读。
- Provider 状态只读展示。
- 账户资料、主题、服务地址和基础设置。
- Android/iOS 深链接到受保护任务详情。

## 4. 非目标

- Web 页面、管理后台、用户/Provider 管理和全局数据分析。
- 批量、播放列表、私有/会员/DRM 媒体或平台凭据导入。
- App 内媒体解析、转码、AI 推理或 Provider 执行。
- 首期分享扩展、推送通知、后台常驻下载和离线媒体库。
- macOS、Windows、Linux 或 Flutter Web 发布。

## 5. 产品规则

- 只展示 API 返回的真实格式、状态和能力，不制造预设或预测文件信息。
- App 关闭或进入后台不能改变服务端任务；重新打开后从服务端恢复。
- 无网络、会话过期、无权限、限流、服务不可用和空间不足必须有明确恢复路径。
- 文件获取前确认可用空间；下载中显示进度并允许取消。
- 合法使用与版权提示在提交解析和保存文件前保持可见。
- 管理能力继续使用 `video-server` Web 平台，不在移动端复制。

## 6. 产品验收标准

- AC-001：Android 与 iOS 使用同一 Flutter 业务实现完成首期流程。
- AC-002：用户可注册、登录、恢复和退出，敏感凭据符合 Design 安全边界。
- AC-003：合法单链接可解析并呈现真实媒体与格式；非法输入不发请求。
- AC-004：用户可创建任务并在前后台切换、断网重连后看到准确状态。
- AC-005：失败、取消和重试不产生重复任务或错误状态。
- AC-006：成功文件可安全下载、取消、重新授权、保存或分享。
- AC-007：历史只展示当前用户任务，并支持规范冻结的查询能力。
- AC-008：AI 分析状态独立于下载状态，失败不改写已成功下载。
- AC-009：受保护深链接在会话恢复后到达目标，失败时安全回到登录。
- AC-010：核心页面覆盖加载、空、失败、离线、会话过期和重试状态。
- AC-011：核心流程支持深浅主题、文字缩放、屏幕阅读器和系统返回手势。
- AC-012：App 不包含 Web、管理后台、Provider 执行或其他非目标能力。
