# 006 原生认证与应用导航需求

- 状态：Accepted
- 日期：2026-08-30

## 用户目标

用户可以在 App 内完成注册、登录、会话恢复和退出，并通过清晰的顶部会话入口与底部一级导航访问完整产品结构。

## 验收条件

- AC-006-01：未登录用户可从顶部栏或“我的”进入独立登录/注册页面，并可在两者之间切换和返回。
- AC-006-02：注册校验用户名、邮箱、密码与确认密码；登录校验邮箱和密码；错误可读且焦点不丢失。
- AC-006-03：真实注册/登录成功后进入 signedIn，账户页显示服务端用户信息。
- AC-006-04：Refresh Credential 只保存于安全存储，Access Token 只在内存；启动恢复、单飞刷新和失败清理生效。
- AC-006-05：退出撤销服务端 Session 并无条件清除本地会话。
- AC-006-06：顶部栏保留文字品牌与会话快捷入口；底部五 Tab 在中英文、大字体下可辨认、可选择且语义完整。
- AC-006-07：Widget/集成测试覆盖注册、登录、校验、失败、恢复、退出、导航与主题；双端构建和模拟器复验通过。
- AC-006-08：agent-browser 对 Server Web 登录注册基线完成桌面/390×844、键盘、错误和账户退出验收；Native App 由 Flutter 自动化与模拟器证据验收。
