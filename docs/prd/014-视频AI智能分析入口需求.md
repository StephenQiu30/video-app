# 014 视频 AI 智能分析入口需求

- 状态：Accepted
- 日期：2026-08-31

## 用户价值

用户完成视频下载后，不必返回 Web 平台即可选择与 Web 同源的 AI Skill，发起分析、跟踪进度、恢复失败任务并阅读经过服务端校验的结果。

## 功能需求

1. 成功下载的详情页显示可访问的“AI 智能分析”入口、能力说明和真实当前状态。
2. 首次分析可选择服务端返回的 Skill、简体中文或 English，并编辑分析重点。
3. 创建操作使用稳定幂等键，重复点击或安全重试不能创建重复业务任务。
4. App 恢复该下载最近一次分析；活跃状态轮询至终态，并支持手动刷新。
5. 活跃分析可取消；失败或取消分析可重试；删除分析必须二次确认。
6. 视觉分析结果完整覆盖摘要、场景、分镜、高光和资产；视频文章结果覆盖导语、章节、要点、结语和局限。
7. 加载、空、创建中、运行中、失败、取消、成功、操作失败和重试状态均有明确反馈。
8. 中文、英文、深浅主题、动态字体、屏幕阅读器和 44×44 触控目标可用。

## 约束

- 结果、进度、Skill 和失败码全部来自生成客户端，不显示模拟远程数据。
- 分析失败不得改变已成功的下载与文件获取能力。
- 不记录完整 Prompt、模型原始响应、Token 或用户媒体。
