# 019 剧本文档详情与跨端一致性需求

## 用户需求

1. 解析成功的剧本文档必须可以从 App 列表点击进入详情，也必须支持直接打开详情路由。
2. App 与 Web 必须读取相同的状态、元数据、解析摘要、规范化正文和剧本分析结果。
3. 上传、解析、详情刷新、删除、分析创建、重试、取消和结果查看必须具备明确反馈。
4. 手机宽度、明暗主题和读屏模式下不得出现截断、横向溢出或误导性状态文案。
5. Web 上传不得依赖浏览器直接访问 Tailscale MinIO；现有 `.env` 与 `.env.prod` 不得被修改。
6. 验收产生的账号、文档、分析、事件和对象存储文件必须全部清理。

## 验收标准

- AC-019-01：文档列表项是可点击且可读屏识别的按钮语义，并打开 `/documents/:documentId`。
- AC-019-02：详情页展示完整导入信息、解析摘要、正文、错误/警告和删除入口。
- AC-019-03：剧本分析使用文档分析接口，支持完整状态机并渲染结构化结果与 Markdown 报告。
- AC-019-04：Web 完成创建文档、上传、完成上传、解析、进入详情的生产链路。
- AC-019-05：390px Web 与标准 iPhone 宽度在浅色、深色主题下均无横向溢出或关键值截断。
- AC-019-06：App 静态分析、完整测试、真实 API 集成测试及 iOS/Android 构建通过。
- AC-019-07：服务端剧本源投影兼容导入 Worker 的真实元数据，并由回归测试覆盖。
- AC-019-08：验收测试数据清零，环境配置文件保持未修改。
