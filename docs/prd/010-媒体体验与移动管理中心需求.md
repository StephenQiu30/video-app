# 010 媒体体验与移动管理中心需求

- 状态：Accepted
- 日期：2026-08-30

## 用户价值

登录用户可以在下载记录中看到真实封面，进入详情后直接观看仍然可用的视频或获取原文件；管理员可以在 App 中完成日常巡检和高频运营操作，不必为每次查看状态都打开桌面 Web 管理台。

## 功能需求

1. 历史记录显示服务端真实封面，封面加载、不可用和失败状态均有明确反馈。
2. 详情页面的标题、媒体、状态、进度、动作和元数据层级与 Web 一致，并保持 Flutter 原生返回与无边框设计。
3. 成功且文件可用的任务可以在 App 内播放，也可以通过系统下载短时地址获取文件。
4. 播放或下载地址必须即时签发、过期可重新获取，不能进入日志或持久化存储。
5. 管理员在“我的”页面看到“管理中心”；普通用户不显示入口且不能通过深链接访问。
6. 管理中心真实展示下载分析、存储文件、用户、平台目录和 AI Provider 数据。
7. 管理员可执行文件清理、用户角色/启停、平台可见性和 AI 线路激活，操作后以服务端结果重新收敛。
8. 所有页面覆盖加载、成功、空、失败、重试、无权限、动态字体、深浅主题和辅助功能语义。

## 约束

- 只使用冻结 OpenAPI 生成模型与请求，不新增手写平行 DTO 或第二个 HTTP 客户端。
- 不把认证头拼进 URL，不缓存短时下载地址，不展示服务端密钥。
- 系统下载能力不可用时必须给出可恢复提示，不能宣称文件已经保存。
