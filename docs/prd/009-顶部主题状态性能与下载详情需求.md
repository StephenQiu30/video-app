# 009 顶部主题、状态性能与下载详情需求

- 状态：Accepted
- 日期：2026-08-30

## 用户价值

用户可以在任何登录后页面快速切换明暗主题，不必进入“我的”；平台状态在用户需要查看时尽快呈现；下载历史不再是不可操作的静态清单，而可以继续查看与 Web 一致的真实任务详情。

## 功能需求

1. 登录后顶部导航显示主题切换按钮，首页、历史、文档、状态、我的和下载详情均可使用。
2. “我的”页面移除重复的外观区，账户与退出登录流程保持不变。
3. 平台状态在主应用加载后预取并在登录会话内缓存；重复切换 Tab 不重复阻塞请求。
4. 下拉刷新平台状态时保留已有数据，刷新完成后原位更新；冷加载、失败、重试语义完整。
5. 历史列表每条真实任务可点击，进入由任务 ID 驱动的独立详情页面。
6. 详情必须再次读取 `GET /api/downloads/{job_id}`，展示服务端真实状态、进度、执行和时间信息。
7. 详情支持返回历史页、下拉刷新、深浅主题、动态字体和辅助功能。

## 约束

- 不用静态 Provider 数据或历史列表对象冒充详情响应。
- 不泄露 Token、完整媒体 URL、预签名地址或服务端原始异常。
- 不承诺本轮未接入的文件下载、播放、重试、取消、WebSocket 与 AI 分析能力。
