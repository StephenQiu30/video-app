# 017 持久解析与原生恢复需求

目标：iOS／Android 用户粘贴公开地址或分享文案后，App 在网络波动、页面切换、进程重建与结果过期时维持同一解析意图，得到可确认规格和真实下载文件。能力仅限服务端当前可正向验证的公开、免费、非 DRM 内容，不以提取器候选数量宣传可下载平台。服务端总需求见 [044 PRD](../../../video-server/docs/prd/044-开源部署无感解析PRD.md)。

- FR-A1：公开输入提交后显示排队、准备、解析、可选规格、需要动作、失败、取消、过期及交接状态；网络未知先只读查询原键。
- FR-A2：同账号重入可从服务端解析记录选择原意图；退出和换账号立即隐藏并清空前一账号内容。
- FR-A3：过期规格不能下载；用户可在原任务更新并重新确认；双击、取消和确认竞争不得创建多个下载 job。
- FR-A4：文章发现、上传、历史、分析与原生 Bearer 鉴权不退化；受限媒体给出明确原因，不索取普通 Cookie。
- NFR-A1：原始分享文案不写持久存储或日志；只读恢复不扣解析额度；POST 不因重连自动重发。
- NFR-A2：前后台与路由切换不清空已确认身份或可用解析结果；失败可重试，轮询有界。
- NFR-A3：契约由服务端 OpenAPI 自动生成；`dart format`、`flutter analyze`、单元／Widget／设备测试通过，双平台版本与服务端契约同发布。

验收以 `docs/acceptance/017-持久解析与原生恢复验收.md` 的实际逐项结果为准。缺真机／模拟器或合格平台样本时保持未验收，不推断所有平台成功。
