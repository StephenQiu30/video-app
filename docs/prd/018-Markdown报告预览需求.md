# 018 Markdown 报告预览需求

## 用户需求

1. 报告预览必须将 Markdown 渲染为可阅读的富文本，不得显示原始 `#`、`**`、表格分隔符等语法。
2. 标题、列表、引用、代码块和 GFM 表格必须具备清晰层级。
3. 视频视觉分析与视频文章报告的预览表现必须一致。
4. 报告必须支持文本选择，并正确适配 App 的明暗主题。
5. Markdown 解析必须使用成熟第三方组件，不重复实现解析器。

## 验收标准

- AC-018-01：两个报告入口均使用共享的 `flutter_markdown_plus` 组件。
- AC-018-02：Widget 测试证明标题与表格不再以原始 Markdown 字符串显示。
- AC-018-03：浅色与深色主题均能构建报告预览。
- AC-018-04：`flutter analyze` 与完整 `flutter test` 通过。
