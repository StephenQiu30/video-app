# 008 真实用户数据接入需求

- 状态：Accepted
- 日期：2026-08-30

## 用户价值

用户登录后应看到自己真实的下载记录和剧本文档，以及服务端当前的平台能力状态；没有数据时应明确说明“暂无数据”，而不是误导为功能未开放。

## 功能需求

1. 历史页请求当前用户下载历史，展示真实总数、成功/进行中/失败汇总和任务字段。
2. 文档页请求当前用户文档，展示真实总数、文件名、格式、大小、处理状态与可用统计。
3. 状态页请求真实平台快照，展示平台名、支持状态、下载可用性、能力与最近验证时间。
4. 三页均支持首次加载、真实空态、错误重试和下拉刷新。
5. 请求必须携带当前原生 Access Token；过期时最多刷新并重试一次，刷新失败回到登录。
6. 切换底部 Tab 不清除首页输入，也不改变现有无边框导航高亮方式。
7. 中英文、深浅主题、动态字体和辅助功能语义必须可用。

## 约束

- 不使用 Mock、浏览器 Cookie、WebView 或手写平行 DTO 充当真实接入。
- 不显示服务端未提供的缩略图、进度、分析结果或文件操作。
- 不在日志或错误界面中显示 Token、完整媒体 URL、预签名地址或服务端敏感细节。
