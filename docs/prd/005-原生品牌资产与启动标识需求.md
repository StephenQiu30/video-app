# 005 原生品牌资产与启动标识需求

- 状态：Accepted
- 日期：2026-08-30

## 用户目标

用户在设备桌面、系统启动过渡和应用内容页看到一致而克制的“帧取”品牌，不再看到 Flutter 默认图标，也不会在内容页面被重复 Logo 占用空间。

## 验收条件

- AC-005-01：Android 桌面图标使用“帧取”Logo，并覆盖传统、圆形和 API 26+ 自适应图标资源。
- AC-005-02：iOS AppIcon 所有必需尺寸使用“帧取”Logo，1024×1024 图标无透明通道。
- AC-005-03：Android 与 iOS 启动过渡显示同一图形标志，不出现 Flutter 默认标识。
- AC-005-04：应用内容页顶部只显示本地化产品名，不重复显示图形 Logo，既有首页布局和导航不回归。
- AC-005-05：品牌源文件进入 App 仓库，来源和用途在 Design 中可追溯。
- AC-005-06：格式、静态分析、测试、Android Debug 与 iOS Simulator 构建全部通过，并完成模拟器视觉复验。
