# 011 账户退出布局与应用图标复核需求

- 状态：Accepted
- 日期：2026-08-30

## 用户目标

用户在“我的”页面按自然顺序查看账户与管理员能力，最后执行退出；并能确认模拟器桌面上的“帧取”使用正确品牌图标。

## 验收条件

- AC-011-01：退出登录不再位于账户信息和管理中心之间。
- AC-011-02：管理员页面中管理中心入口位于退出登录之前。
- AC-011-03：退出登录为无边框、全宽左对齐的最终危险操作，忙碌时禁用且退出流程不回归。
- AC-011-04：iOS `com.stephenqiu.framegrab` 显示名为“帧取”，桌面入口使用蓝色“播放 + 下载”图标。
- AC-011-05：iOS AppIcon 1024×1024 源无 Alpha，Android 传统、圆形和自适应资源继续完整。
- AC-011-06：格式、静态分析、自动化测试、Android Debug、iOS Simulator 构建与模拟器视觉复验通过。
