# PRD 004 AI 内容提取交互需求

## 文档状态

- 状态：Accepted for Planning（2026-07-19）。
- 上游：[Design 004](../design/004-AI内容提取交互设计.md)。
- 输入：成功下载、AI job 状态和结构化分析 VO。
- 输出：AI 创建、轮询、结果、错误和能力提示需求。
- 下游：[Plan 004](../plans/004-AI内容提取计划.md)。

## 1. 背景与价值

用户可以在下载成功后选择获取视频语音摘要，而不影响文件下载。界面必须避免把语音转写包装成字幕或画面理解能力。

## 2. 产品目标

1. 只从成功且未过期下载创建 AI 任务。
2. 默认请求中文结果并防止重复提交。
3. 展示 queued、running、succeeded、failed、expired。
4. 以摘要、核心要点、章节三段展示结果。
5. 明确结果只基于语音并可能存在误差。

## 3. 非目标

- 不显示或下载字幕，不显示完整内部转写。
- 不展示画面理解、Prompt、模型、Provider、Token 或 API Key。
- 不提供用户调整 AI 参数的界面。

## 4. 状态和结果规则

- 创建时提交默认 `output_language=zh-CN`，按钮 loading 且不自动重放。
- queued/running 每 2 秒轮询，展示 transcribing/analyzing stage。
- succeeded 展示非空 summary、key points 和 chapters。
- chapters 每项展示起止时间、标题和摘要，并使用语义列表。
- failed 显示安全错误；expired 不伪造空结果。

## 5. 首版验收门禁

- `W004-AC-01`：只有合法下载状态显示 AI 入口，重复点击不创建多任务。
- `W004-AC-02`：创建默认中文并跳转真实 AI job ID。
- `W004-AC-03`：五种任务状态和两个 running stage 表达准确。
- `W004-AC-04`：三个结果区域完整映射 VO，缺失结构视为错误。
- `W004-AC-05`：转写、分析、查询和过期错误均有恢复路径。
- `W004-AC-06`：页面明确非字幕、非画面理解和误差提示。
- `W004-AC-07`：长文本、章节、动态进度在手机和辅助技术下可用。

## 6. 待确认问题

无。画面理解、多语言选择和完整转写展示需单独设计。
