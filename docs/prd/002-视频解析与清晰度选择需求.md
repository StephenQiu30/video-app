# PRD 002 视频解析与清晰度选择需求

## 文档状态

- 状态：Accepted for Planning（2026-07-19）。
- 上游：[Design 002](../design/002-视频解析与清晰度选择交互设计.md)。
- 输入：单视频 URL、解析 VO、格式列表与 15 分钟有效期。
- 输出：下载工作台输入、解析、视频信息和格式选择需求。
- 下游：[Plan 002](../plans/002-视频解析与清晰度选择计划.md)。

## 1. 背景与价值

用户应当只需粘贴链接并选择可理解的清晰度，不需要了解平台格式 ID、selector、音视频分离流或底层下载工具。

## 2. 产品目标

1. 提供单一、明确的视频链接输入和解析操作。
2. 展示标题、平台、时长、缩略图和结果过期时间。
3. 展示服务端推荐格式并默认选择首项。
4. 在解析失败或过期后提供明确恢复路径。
5. 创建下载任务后进入独立任务详情页。

## 3. 非目标

- 不展示原始 URL、selector、provider format ID、字幕、播放列表或音频-only。
- 不提供历史、批量、平台参数或 Cookie 输入。

## 4. 核心场景

- 初始：只显示输入、主按钮、能力和合法使用提示。
- 解析中：保留输入，按钮 loading，禁止重复提交。
- 成功：展示视频 Card、格式单选和下载按钮。
- 失败：保留输入和错误，允许修改后重试。
- 过期：提示重新解析，禁止创建下载。

## 5. 展示规则

- 格式显示 label、container、FPS、estimated size 和 requires merge 提示。
- size 为 null 时显示“大小未知”，不能显示 0。
- 新链接解析时清空旧结果、旧选择和旧错误。
- 解析结果明确显示“15 分钟内有效”和绝对过期时间。
- 原始视频 URL 不进入路由 query、页面标题、日志或错误上报。

## 6. 首版验收门禁

- `W002-AC-01`：空值和非 HTTP/HTTPS 在请求前就地校验。
- `W002-AC-02`：idle、inspecting、inspected、failed、expired 状态互斥且反馈明确。
- `W002-AC-03`：视频信息与格式字段按 VO 正确呈现，默认首项稳定。
- `W002-AC-04`：大小 null、requires merge 和过期行为符合规则。
- `W002-AC-05`：创建成功跳转真实 job ID，POST loading 时不重复提交。
- `W002-AC-06`：输入、单选、错误和 loading 对键盘及辅助技术可读。
- `W002-AC-07`：页面不出现字幕、音频下载或底层 selector。

## 7. 待确认问题

无。新增格式筛选或批量输入需另行设计。
