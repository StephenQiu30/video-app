# 015 公开首页与持久主题需求

- 状态：Accepted
- 日期：2026-08-31

## 用户价值

用户无需先注册即可理解 FrameFetch 的开源、自托管定位和主要能力；决定使用后再登录访问受保护工作流。浅色与深色主题在整个 App 中一键切换，并在重新启动后保持。

## 功能需求

1. 无有效会话时，根路由显示原生公开项目首页，不自动跳转登录。
2. 公开首页展示项目定位、视频工作流、剧本文档、AI 分析和数据控制说明。
3. 公开首页提供登录、注册与可访问的主题按钮。
4. 任务详情、管理页面和登录后真实数据继续要求有效 Bearer 会话。
5. 登录或注册成功进入下载工作区；退出后回到公开首页。
6. 主题仅包含浅色和深色，按钮一次点击完成切换。
7. 主题入口覆盖公开首页、登录注册页和登录后页面，选择持久化到非敏感系统偏好。
8. 中文、英文、390×844、大字体、屏幕阅读器、Android 与 iOS 均不得出现溢出或语义退化。
9. App 公开首页必须与 Web SEO/项目介绍页保持同一内容基线，覆盖统一标语、完整工作链路、产品能力、自托管技术栈、安全边界和本地部署说明。
10. 两端的原生布局可以不同，但不得以 App 空间有限为由省略项目定位或关键边界信息。
11. App 公开页中英文文案必须来自 ARB，本地代码不得散落同义硬编码；仓库与 Quick Start 链接必须集中配置。
12. App 公开首页提供创建本地账户、查看源代码和阅读部署说明三个明确入口，登录入口和认证边界保持不变。

## 验收边界

- Widget 测试覆盖匿名首页、主动登录、受保护路由、退出落点、主题切换与恢复。
- Widget 测试锁定 Web 对齐的中文核心文案，并覆盖中英文、390×844 和无障碍大字体下的完整滚动内容。
- 运行格式、分析、全量测试和非 Debug 发布构建。
- 在连接的 iPhone 上安装非 Debug App，并人工确认公开首页、登录入口、外部链接和主题切换。
