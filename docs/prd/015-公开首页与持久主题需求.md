# 015 公开首页与持久主题需求

- 状态：Accepted
- 日期：2026-08-31

## 用户价值

用户无需先注册即可理解 FrameFetch 的开源、自托管定位和主要能力；决定使用后再登录访问受保护工作流。浅色与深色主题在整个 App 中一键切换，并在重新启动后保持。

## 功能需求

1. 无有效会话时，根路由显示原生公开项目首页，不自动跳转登录。
2. 公开首页展示项目定位、视频工作流、剧本文档、AI 分析和数据控制说明。
3. 公开首页提供登录、注册与可访问的主题按钮。
4. 任务详情、管理页面和登录后真实数据继续要求有效 Bearer 会话。
5. 登录或注册成功进入下载工作区；退出后回到公开首页。
6. 主题仅包含浅色和深色，按钮一次点击完成切换。
7. 主题入口覆盖公开首页、登录注册页和登录后页面，选择持久化到非敏感系统偏好。
8. 中文、英文、390×844、大字体、屏幕阅读器、Android 与 iOS 均不得出现溢出或语义退化。

## 验收边界

- Widget 测试覆盖匿名首页、主动登录、受保护路由、退出落点、主题切换与恢复。
- 运行格式、分析、全量测试、Android Debug 和 iOS Simulator 构建。
- 在连接的 iPhone 上安装 Debug App，并人工确认公开首页、登录入口和主题切换。
