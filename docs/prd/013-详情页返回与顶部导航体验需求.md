# 013 详情页返回与顶部导航体验需求

- 状态：Accepted
- 日期：2026-08-31

## 用户价值

用户从创建结果、下载历史或外部链接进入详情后，始终能看见并使用符合设备习惯的返回入口；正常返回时保留上一页上下文，直接打开详情时也不会被困在页面内。

## 功能需求

1. 下载详情顶部始终显示可访问的返回按钮与主题切换按钮。
2. 创建任务后进入详情必须保留首页路由，返回后恢复此前输入与解析结果。
3. 从下载历史进入详情后，返回时仍停留在历史 Tab。
4. 深链接直接进入下载详情且没有可弹出的路由时，返回按钮进入登录后首页。
5. 管理中心和管理子页复用相同行为，并使用与页面层级一致的回退目标。
6. 返回按钮满足至少 44×44 触控目标、中文与英文语义、深浅主题和 iOS 平台图标要求。

## 约束

- 返回行为必须由 `go_router` 的现有栈和声明式地址完成。
- 不丢失首页的本地状态，不新增服务端请求或持久化数据。
