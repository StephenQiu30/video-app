# 004 Server 当前普通用户页面同步需求

- 状态：Accepted
- 日期：2026-08-27
- Server 基线：`video-server` `8bb2e91`

## 1. 用户价值

App 用户看到的入口、页面名称和能力说明与当前 Server 保持一致，不会继续停留在只有单视频解析的旧产品结构，也不会把尚未冻结的移动端接口误认为已经可用。

## 2. 功能需求

1. 首页标题与说明覆盖链接、本地视频和剧本文档三种素材。
2. 用户可以在三个入口间切换，返回链接入口时已输入 URL 不丢失。
3. 链接文案覆盖公开视频、微信视频号单作品与微信公众号文章；文章多视频需要在未来真实结果中显式选择。
4. 底部导航包含首页、下载记录、剧本文档、平台状态与我的。
5. 下载记录说明包含任务恢复、完成后预览、文件和 AI 分析。
6. 剧本文档说明包含上传、规范化预览、分析和改写。
7. 平台状态说明包含接入、访问、检查、下载和完整分析证据。
8. 未冻结的上传、查询和远程解析动作不得发起真实请求，必须返回准确的契约待接入说明。

## 3. 验收标准

- AC-004-01：390×844 下三种素材入口与五项导航完整可见，无横向溢出。
- AC-004-02：切换底部页面或素材入口不会清空链接输入。
- AC-004-03：剧本文档拥有独立一级页面，不再缺失于 App 导航。
- AC-004-04：页面文案与 `video-server` 当前普通用户能力一致，并明确原生 E2E 仍阻塞。
- AC-004-05：Widget 测试覆盖入口切换、导航、输入保留和契约反馈。
- AC-004-06：390×844 的中英文界面在系统辅助功能大字体下不发生布局溢出；三种素材入口与五个一级目的地仍可辨认、可选择并保留完整语义名称。
