# 012 真实媒体解析与下载创建需求

- 状态：Accepted
- 日期：2026-08-31

## 用户目标

登录用户粘贴有权处理的公开视频或公众号文章链接，或整段包含唯一链接的平台分享文案后，可以看到真实解析结果、选择下载格式、创建下载任务并立即查看进度。

## 验收条件

- AC-012-01：有效普通链接或包含唯一 HTTP(S) URL 的平台分享文案点击“解析媒体”会真实调用 `inspectMedia`，不再显示契约占位提示。
- AC-012-02：公众号文章真实调用来源发现；多个候选视频必须由用户选择后解析。
- AC-012-03：解析结果展示真实封面、标题、平台、时长及服务端返回的全部格式。
- AC-012-04：用户可以选择格式，并用同一解析资源创建真实下载任务。
- AC-012-05：创建成功后打开真实下载详情，历史列表刷新后包含新任务。
- AC-012-06：非 downloadable 决策、空格式、限流、会话失效、网络与服务错误均有准确反馈且不创建任务。
- AC-012-07：实现只使用生成 OpenAPI 客户端和当前 Bearer 契约，不存在可空意图、旧占位或兼容 fallback。
- AC-012-08：格式、静态分析、自动化测试、生成契约漂移、Android Debug、iOS Simulator 与真实服务 E2E 全部通过。
- AC-012-09：长格式清单不会埋住创建入口；活动任务自动刷新真实进度，终态不继续轮询。
