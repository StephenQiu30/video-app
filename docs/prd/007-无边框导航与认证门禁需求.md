# 007 无边框导航与认证门禁需求

- 状态：Accepted
- 日期：2026-08-30

## 用户价值

用户进入 App 时应立即知道自己是否已登录；只有通过认证后才能看到素材处理与账户数据。主框架应像原生移动产品，而不是重复 Web 顶栏：品牌只出现一次，首页和账户只通过底部 TabBar 进入。

## 功能需求

1. 启动时恢复原生会话，恢复中显示品牌加载状态。
2. 未登录用户只能使用登录、注册及二者之间的切换。
3. 登录或注册成功后进入首页；退出、Refresh 失效或本地凭据无效后回到登录页。
4. 顶部 Navbar 不显示“首页”、登录按钮、用户名或账户按钮。
5. 底部 TabBar 包含首页、历史、文档、状态、我的；所有标签持续可见。
6. 底部 TabBar 选中态不使用短横线、边框、药丸或卡片，只通过 Lucide 图标颜色和字重高亮。
7. 首页三入口继续可切换并保留现有输入状态。
8. 中文、英文、深浅主题与辅助功能文字缩放均不得发生溢出或语义退化。
9. 登录后的数据页、详情页、分析页和管理页不得使用装饰性 Divider、Card 外框或 OutlinedButton 制造容器感；信息层级只通过留白、排版与必要的实心表面表达。

## 验收边界

- 390×844 iOS Simulator 是主视觉基线。
- Android Debug 与 iOS Simulator 必须构建通过。
- Widget 测试必须覆盖未登录门禁、会话恢复、登录后重定向、退出回登录和五 Tab 语义。
- 真实服务集成必须覆盖清空凭据后启动即登录、注册成功进入主框架和退出回登录。
