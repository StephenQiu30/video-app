# 授权视频下载与 AI 知识化 Web MVP

## 1. 用户价值

用户通过一个可信入口完成授权来源探测、真实清晰度选择、异步下载、AI 内容整理和 PDF 导出；每个阶段都有可恢复状态、明确失败原因、合规边界和删除能力。

## 2. 成功指标

- 来源提交到清晰度目录 p95 ≤8 秒。
- 支持来源解析成功时，规格字段展示准确率 100%。
- 负向来源的阻断原因和用户动作映射覆盖率 100%。
- 刷新、断网和事件重连不创建重复任务。
- 375、768、1440 px 主流程无阻断性布局问题。
- Playwright + axe 无 serious/critical 问题，完整流程可只用键盘完成。
- 入口页 p75 目标：LCP ≤2.5s、INP ≤200ms、CLS ≤0.1。

## 4. 用户故事

1. 作为内容创作者，我能在提交前理解支持范围并确认处理权。
2. 作为编辑，我能比较真实规格并知道是否包含音频、需要合并及预计大小。
3. 作为用户，我关闭或刷新页面后仍能恢复后台任务。
4. 作为学习者，我能从时间证据跳转到对应章节并校对摘要。
5. 作为键盘或屏幕阅读器用户，我能完成同等流程并读取所有状态。
6. 作为隐私敏感用户，我能只下载而不启用 AI，并能删除自己的数据。

## 5. 非目标

- 在浏览器或 Next.js 中执行下载、转码、AI 或 PDF。
- 通过前端绕过 DRM、平台限制、登录或 Cookie。
- 手写与 OpenAPI 平行的接口类型。
- 批量、播放列表、直播、浏览器扩展、桌面端和管理后台。
- MVP 首次交付公开分享、团队协作、计费或模板市场。
- 用假进度、假清晰度或假 AI 结果填充未完成能力。

## 6. 关键页面

- `/`：说明、来源输入、权利确认、Probe 与 Variant。
- `/tasks/[taskId]`：下载、AI、思维导图和 PDF 的可恢复工作台。
- `/library`：私有历史、重签、重试和删除。
- `/legal/supported-sources` 与 `/privacy`：政策与数据处理。

## 7. 状态与恢复

Probe、Download、Analysis、Export 各自建模。任务 ID 进入 URL；服务器快照是事实来源。事件流只更新即时状态，终态后重新拉取。未知总量不显示百分比；部分成功保留已成功产物。

## 8. 隐私与安全

URL 查询参数、Cookie、Token、源站媒体 URL 和 AI 正文不得写入客户端日志或分析事件。所有服务端文本按不受信内容渲染；禁止不受控 HTML。下载授权与 AI 数据处理同意分开。Plan 001 默认本地单用户运行，安装令牌只存在于 Next.js 服务端；无受信身份边界时不得作为公网多用户产品部署。

## 9. 依赖顺序

`Plan 001 → Plan 002 → Plan 003 → Plan 004`。每个 Plan 的 Acceptance 全部通过后再解锁下一个；后续 Plan 不得向前一个 Plan 注入假实现。

## 10. 风险

- OpenAPI 在两仓漂移。
- SSE 断线或事件乱序造成错误 UI。
- 复杂规格在移动端不可比较。
- 思维导图只做画布会造成无障碍缺口。
- 第三方缩略图、字体或分析脚本泄露用户来源信息。
