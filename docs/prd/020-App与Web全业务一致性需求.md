# App 与 Web 全业务一致性需求

状态：Accepted。

1. 两端邮箱+密码登录、邮箱验证码注册使用相同规则和结果；密码 8–128 个 Unicode 字符，邮箱变化清空旧验证码。
2. 用户能访问所有历史、文档、管理用户和文件记录，不能只取第一页；筛选与搜索不得停留在过期页码。
3. App 支持 Web 已有的资料修改、可用报告 DOCX 导出、完成后重新分析及配置管理操作。
4. 相同权限和资源状态决定相同可操作范围；不可删除活动 AI 线路或内置 Codex，不可修改自己的管理员权限。
5. 中文文案保持同一业务含义；所有新增 ARB 条目同时提供英文。不同终端的布局、图表表达与系统文件保存流程可以不同。

不增加新的账户体系、后台下载、支付、推送、分析引擎或第三方 SDK。详情与逐页结果见对应设计和验收。
