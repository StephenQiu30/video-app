# 003 方案一视觉深化与 Web 普通用户功能对齐需求

- 状态：Accepted
- 日期：2026-08-13

## 1. 用户价值

用户在 App 中获得与 Web 同一品牌和任务心智，同时使用更符合手机习惯的底部导航、键盘、返回、文件与辅助功能体验。普通用户不因切换到 App 而失去 Web 已有的解析、下载、历史、分析、平台和账户能力。

## 2. 范围

- 按方案一深化首页及四个底部目的地的统一视觉系统。
- 保留本地 URL 归一化、校验、加载、错误和契约阻塞反馈。
- 功能规划覆盖解析、格式、任务、历史、AI 分析、平台状态、注册登录、资料和退出。
- 管理后台继续由 Web 提供，不进入 App。

## 3. 验收标准

- AC-003-01：Flutter 组件与图标体系明确、可访问、可在 iOS/Android 运行。
- AC-003-02：首页与 Web 使用同源 Logo、色彩、圆角、图标与编辑式层级。
- AC-003-03：底部目的地之间切换不丢失首页输入状态。
- AC-003-04：服务契约缺失时准确说明阻塞，不发送真实业务请求或展示伪数据。
- AC-003-05：原生契约冻结后，001 定义的普通用户 E2E 能力全部通过真实服务验收。
