# Plan 004：PDF、历史与数据生命周期

## 1. 前置门禁

Plan 003 与服务端 PDF Plan 完成；结构化编辑版本、PDF、资产和删除契约稳定。

## 2. 范围

- 编辑结构化知识文档并保存版本。
- 触发 PDF、展示渲染状态、下载和过期重签。
- PDF 中提供可选择文本、标题层级、链接和思维导图大纲。
- `/library` 私有历史、筛选、失败重试、删除和保留期提示。
- 立即删除确认、结果失效和审计反馈。

## 3. 非目标

公开分享、协同编辑、模板市场、永久归档和计费。

## 4. 核心验收

- PDF 与用户最后保存版本一致，导出不重新生成 AI 内容。
- 签名链接过期可重签，删除后所有入口立即不可访问。
- 纯键盘可完成编辑、导出、重签和删除。
- 375、768、1440 px 无乱码、裁切或阻断操作。
