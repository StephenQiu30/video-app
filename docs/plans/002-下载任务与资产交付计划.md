# Plan 002：下载任务与资产交付

## 1. 前置门禁

Plan 001 与服务端下载 Plan 已完成，Variant、Job、SSE、current rights、`permitted_operations` 和资产契约稳定。

## 2. 范围

- 仅当 server PolicyView 明确含 `download` 时展示下载动作；创建前重新展示 current rights 并取得确认，再用选定 `format_key` 和幂等键创建下载。
- probe-only、policy stale/revoked、rights stale 或远端身份变化必须清晰阻断，不能把“已探测”呈现为“可下载”。
- `/tasks/[taskId]` 状态轨、可空进度、速度/字节/ETA、取消与有限重试。
- SSE `Last-Event-ID` 恢复与轮询兜底，刷新不重建任务。
- 最终媒体信息、签名地址下载和链接过期重签。
- 大文件直接从对象存储下载，不经过 Next.js。

## 3. 非目标

AI、思维导图、PDF、批量、直播、浏览器扩展和 DRM 绕过。

## 4. 核心验收

- 创建请求的 `format_key` 与选择一致。
- probe-only UI 无下载入口；伪造请求仍由 server 拒绝；operator-owned download grant 才有正向创建路径。
- 进度不倒退，未知总量不显示假百分比。
- 刷新、断网和 SSE 失败均可恢复同一任务。
- 取消与重试动作状态明确且不会重复创建资产。
- 签名链接过期只重签，不重新下载。
