# Plan 004 AI 内容提取计划

## 状态与输入

- 状态：Ready；尚未开始实现。
- Design：[004](../design/004-AI内容提取交互设计.md)。
- PRD：[004](../prd/004-AI内容提取交互需求.md)。
- 目标：完成 AI 任务创建、轮询、结果、错误和能力边界提示。
- 依赖：Web Plan 001、003、005；Server Plan 004、005。

## 1. 任务边界

只实现 `/ai/jobs/:jobId` 及下载页 AI 创建动作。不显示字幕、完整转写、画面理解、模型或 Prompt 配置。

## 2. 执行拆分

| 顺序 | Test-first 约束 | 最小实现 | 产出 |
| --- | --- | --- | --- |
| 1 | 合法下载状态和默认中文测试先失败 | AI create mutation | 创建行为 |
| 2 | loading/queued/running stage 测试先失败 | AI job query/page | 处理进度 |
| 3 | 2 秒轮询与终态停止测试先失败 | React Query 配置 | 受控轮询 |
| 4 | summary/key points/chapters 测试先失败 | 三个 ProCard 结果组件 | 结果展示 |
| 5 | failed/expired/结构缺失测试先失败 | Result/Error 分支 | 安全失败 |
| 6 | 非字幕/非画面提示与长文本测试先失败 | 提示、语义和响应式 | 能力边界 |

## 3. 测试数据

- 使用生成的 AIJobVO/VideoAnalysisVO fixture。
- 覆盖 transcribing、analyzing、空/缺失字段、长摘要、多章节和业务错误。
- 结果结构缺失必须失败，不能用默认空数组伪装成功。

## 4. 验收映射

- W004-DAC-01：任务 1 的准入、默认语言、去重和真实创建证据。
- W004-DAC-02、W004-DAC-03：任务 2、3 的状态、stage、轮询停止和取消矩阵。
- W004-DAC-04、W004-DAC-05：任务 4 的真实结果、严格 schema 和敏感输出扫描。
- W004-DAC-06：任务 5 的转写/模型/查询/过期故障矩阵。
- W004-DAC-07：任务 4、6 的边界提示、语义、长文本和焦点证据。
- W004-DAC-08：下载成功页到真实 AI 结果的浏览器端到端闭环。
- W004-AC-01、W004-AC-02：创建准入、去重、默认中文和跳转测试。
- W004-AC-03：状态与 stage/轮询测试。
- W004-AC-04：三个结果组件和 schema 缺失测试。
- W004-AC-05：错误恢复矩阵。
- W004-AC-06、W004-AC-07：边界文案、语义列表、手机和辅助技术测试。

## 5. 验证命令

- `npm run test:coverage` 运行 AI 页面目标测试及全量测试并执行覆盖率门禁。
- `npm run tsc`、`npm run biome:lint`、`npm run build`。
- 连接真实 Server 后验证 AI 创建、两阶段进度、结果、失败和过期。

## 6. 提交顺序

`test: AI 创建状态约束 → impl: AI 任务页 → test: 结果错误约束 → impl: 结果展示 → test/refactor: 能力提示与可访问性`

## 7. 风险与非目标

- AI 输出长度不可预测，必须验证超长内容布局。
- 不在 Web 为 Provider 差异增加兼容解析。

## 8. 完成条件

W004-DAC-01 至 DAC-08 与 W004-AC-01 至 AC-07 必须全部 `passed`，真实 AI 端到端、故障矩阵、边界提示和完整浏览器证据齐全后进入 Acceptance。
