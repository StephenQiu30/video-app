# Plan 003：AI 知识文档与思维导图

## 1. 前置门禁

Plan 002 与服务端 AI Plan 完成；AI 数据处理说明、Provider、结构化 Schema 和证据契约稳定。

## 2. 范围

- 独立 AI 同意、供应商/区域/保留说明与只下载路径。
- 转写、摘要、章节、核心观点、术语、行动项和低置信度展示。
- 时间证据跳转与人工编辑。
- React Flow 思维导图和等价语义树形大纲。
- `partial_ready`、分阶段重试和不覆盖成功结果。

## 3. 非目标

身份/情绪推断、画面多模态、AI 对话、公开分享和 PDF。

## 4. 核心验收

- 每个可验证事实可访问时间证据。
- 无音轨/低置信度不显示编造内容。
- 画布与大纲内容一致，键盘和移动端可用。
- AI 失败不影响已成功下载，部分成功可单独重试。
