## 已确认事实

- `http://127.0.0.1:8111/health/ready` 返回 200，API 与 Web 容器健康；不能把截图直接归因于服务离线。
- 当前 Web `/history` 在既有浏览器会话中加载成功：共 75 项、已完成 74、进行中 0，并显示封面、元数据、获取文件、删除和分页。

- Web 请求层会解包统一响应的 `data`；App 生成客户端尝试把整个包装对象反序列化为业务模型。
