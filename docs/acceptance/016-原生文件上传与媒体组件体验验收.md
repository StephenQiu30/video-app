## 2026-09-08 上传超时与取消验收

- AC-016-08/09：行为回归通过。上传具有连接、发送、接收及整体期限，单片失败立即取消其余分片；首页可取消并重新选择文件。会话变化或旧操作结束后的进度、成功、失败都不覆盖当前操作；各请求绑定原会话，认证重放复用创建幂等键。
- 新增 24 项回归，上传相关共 34 项通过。两项 HTTP 悬挂复现先失败后通过：收到请求体但不返回响应头；一片失败而另一片不返回。另用本机 HTTP、真实生成客户端和 Controller 验证总预算结束后显示失败，避免误显示为用户主动取消。
- 覆盖视频/剧本创建和完成、认证重放、取消清理、选择器迟到返回、退出/销毁及中英文首页取消后再次上传。测试见 [`multipart_upload_cancellation_test.dart`](../../test/unit/features/upload/multipart_upload_cancellation_test.dart)、[`content_upload_repository_test.dart`](../../test/unit/features/upload/content_upload_repository_test.dart)、[`content_upload_controller_test.dart`](../../test/unit/features/upload/content_upload_controller_test.dart)、[`content_upload_timeout_test.dart`](../../test/unit/features/upload/content_upload_timeout_test.dart) 与 [`upload_cancellation_test.dart`](../../test/widget/features/upload/upload_cancellation_test.dart)。
- 全量 173 项单元/Widget 测试、格式、静态分析及 Android Debug/iOS Simulator 构建通过。专用 iPhone 17e / iOS 26.5 模拟器对接已运行的 API，现有 `integration_test` 3/3 通过：其中上传用例通过真实生成客户端上传合成 MP4 与 Fountain 文档，完成分片、删除资源并核对列表。该用例直接提供本地测试文件，不代表本轮操作了真实系统文件选择器。
- 本轮结论：修复通过。测试创建的 3 个账号、2 个资源及关联记录已定向清理；相应对象前缀和未完成 multipart 均验证为空。
