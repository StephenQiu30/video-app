# 016 原生文件上传与媒体组件体验验收

- [x] App OpenAPI 包含视频/文档 create、upload-session、complete 与文档 cancel 操作，生成客户端无手改。
- [x] 本地 MP4 可经系统选择器选择、校验、哈希、分片上传并进入下载详情。
- [x] 剧本文档可经系统选择器选择、校验、哈希、分片上传并刷新文档列表。

- [x] `flutter analyze`、`flutter test`、集成测试、Android Debug 和 iOS Simulator 构建通过。
